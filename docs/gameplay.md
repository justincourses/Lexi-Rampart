# 玩法说明

「符文守护」是一款 **三消 × 塔防** 浏览器小游戏：在 7×7 棋盘上交换相邻符文，用消除所得的余烬、奥能、修复与补强资源守住城墙，抵御无限波次的敌军。

在线试玩：<https://rune-rampart.pages.dev/>

## 基础操作

- 点击两枚相邻符文可以换位；也可以按住一枚符文，只向上下左右的可用邻位拖动。松开后两枚符文会滑动交换，没有形成消除时会滑动换回原位。
- 每完成一组消除获得 1 点补强；四连额外 `+1`，五连及以上额外 `+2`，铸币组再额外 `+1`。补强会按当前升级策略强化军械：初次升级消耗 26 点；前几级每次 +10，之后每次 +2（随装备等级持续上升，无硬顶）。
- **红曜石**：每枚储备 1 次余烬齐射（基础上限 24，攻击每升一级 +4）。弩炮开火时整轮弹丸伤害提高 25%，并消耗 1 次。
- **蓝晶**：每枚转化 2 点奥能，连续坠落会提高收益；消耗 18 点可点击「奥术齐射」或按 `Q` 攻击全场。奥能上限随攻速装备成长。
- **绿晶**：立即修复城墙，只记录实际恢复的耐久；城墙已满时不会产生虚假修复数值。
- **铸币**：除颜色收益外，铸币消除组额外获得 1 点补强。
- 连续坠落会放大奥能、修复与军功收益，不会重复放大补强，方便估算升级进度。
- 弩炮持续追踪距离城墙最近的目标。敌人抵达城下后会扣除城墙耐久。
- 敌人防御会降低弩炮和奥术齐射伤害；城防等级会降低敌军突破时造成的伤害。
- 每波都有建议消除组数。需要安排余烬、奥能、补强和修复，才能跟上后期压力。
- 资源增减会在对应 HUD 显示 `+N` / `-N`，并配合战场浮字、日志、进度条或弹丸特效；资源已满时会明确显示「已满」。
- 萌新、老兵与大佬均为 **无限防御**：波次持续推进，直到城墙失守，不设置终局胜利波次。

## 难度

欢迎界面提供三个难度，默认 **萌新**。右上角「战役选项」会暂停当前战局并重新打开欢迎界面；确认出征会按所选难度重开。

| 难度 | 特点（概要） |
| --- | --- |
| 萌新 | 压力较低，每波建议消除约 4 组起；敌人彩蛋怪每波最多 3 个 |
| 老兵 | 介于萌新与大佬之间的持续压力；敌人彩蛋怪每波最多 1 个 |
| 大佬 | 更高密度与更陡曲线；不会出现敌人彩蛋怪，棋盘彩蛋也更稀少 |

第 1–10 波是适应和军械发育阶段，初始敌军更弱并平滑恢复到标准压力。从第 11 波起，所有难度都会逐波提高敌军生命、攻击、防御与速度；每 10 波一次 Boss，下一波进入新的压力阶段。为避免极高波次生成过多 DOM，敌军数量与单批规模会封顶，但属性仍会逐波增强。

大佬难度面向理想操作校准：需要达到每波建议消除量，并合理使用余烬、暴击、奥术齐射、彩蛋与均衡补强。适应期结束后，普通高效率操作会在中后段失守，只有更稳定的资源循环才能继续推进。

难度数值定义在 `src/config/game-config.js`；波次与平衡公式见 `src/game/combat-math.js`。

## 敌军与彩蛋效果

- **速度型**：低生命与防御，快速逼近城墙。
- **攻击型**：突破防线后造成高额伤害。
- **防御型**：移动缓慢，高生命与高防御。
- **均衡型**：各项能力较为平均。
- **Boss**：独立外观、首领预警与更高综合属性。

敌人彩蛋与棋盘彩蛋使用独立概率。击败彩蛋怪或消除彩蛋方块后，弩炮会在有限弹丸次数内获得 **爆裂范围伤害**、**霜缚减速** 或 **破甲**；每发弹丸消费 1 次（三连发消费 3 次），且每枚弹丸锁定发射时领取的符文。多个彩蛋按触发顺序排队；HUD 显示当前效果、剩余弹丸数和候命数量。

## 升级与控制

补强默认使用「自动」策略，优先补齐最低等级装备。可随时切换为攻击、防御或攻速优先；选择会持续影响后续补强，直到重开游戏。

界面布局概要：

- 战场左上角微型 HUD：攻击、防御、攻速
- 「下一次升级」模块下方：完整军械数值
- 右上角：当前威胁
- 微型 HUD 下方：彩蛋符文状态
- 战场左下角：军情日志

攻速等级不仅缩短攻击间隔，也会改变发射表现。攻速达到 4、7、10 级时，弩炮依次解锁双连发、三连发、四连发；额外弹丸使用较低单发伤害，以免破坏战役平衡曲线。

| 操作 | 效果 |
| --- | --- |
| `Q` | 发动奥术齐射 |
| `Esc` | 暂停 / 继续；欢迎界面打开时关闭该界面 |
| 右上角按钮 | 战役选项、全屏、MIDI 配乐、战斗音效、暂停 |

## 本地存档与续战

进度保存在浏览器 `localStorage`（不会上传服务器，也不跨设备同步），主要包括：

- 最后选择的难度
- 音效 / 配乐开关与曲目
- 未完成战役（波次、棋盘、资源、装备、敌军、彩蛋队列等）

每一波开始时写入稳定检查点；主动暂停、切到后台或离开页面时会更新当前状态。若页面恰好在三消动画中关闭，则保留该波开始时的稳定检查点，避免恢复出残缺棋盘。

下次打开会先显示未完战报：可继续保存的波次，或归档旧进度并回到难度选择。战败或主动重新部署会清除战役进度，但保留最后难度选择。旧版「新手」存档会自动迁移到萌新；旧版通关战报继续保留。

实现上 key 定义在 `src/game/constants.js` 的 `STORAGE_KEYS`，逻辑在 `src/game/save.js` / `storage.js` / `history.js`。改存档形状时需提供迁移，并覆盖续战路径；详见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 配乐与音效

背景音乐由 Web Audio 按 MIDI 音符序列实时合成，使用独立开关，并在暂停、切后台、战败或结算时停止。

战斗音效来自 [Kenney](https://kenney.nl/)，采用 Creative Commons **CC0** 许可：

- [Kenney UI Audio](https://kenney.nl/assets/ui-audio)
- [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds)

原始许可文本：`public/assets/audio/ui/License.txt`、`public/assets/audio/impact/License.txt`。
